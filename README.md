# BudgetBuddy Digital Marketing Campaign

This project presents a complete digital marketing campaign for a fictional personal finance app called BudgetBuddy.

## Project Includes:
- Campaign Strategy & Planning
- Social Media Content (Posts & Ads)
- Email Marketing Design
- Performance Analysis (Mock Data)
- Presentation Slides

## Tools Used:
- Canva (Design)
- Microsoft PowerPoint
- Microsoft Word

## Objective:
To demonstrate understanding of digital marketing concepts including audience targeting, content creation, and campaign analysis.
